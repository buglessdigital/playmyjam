5 Ağustos 2026: TR/EN desteği tamamlandı (müşteri yüzü). Çeviri **derleme öncesi** üretilir —
`npm run i18n:translate` TR sözlüğü Google Cloud Translation API v2'ye gönderip `en.json`
üretir, sonuç commit'lenir. Çalışma anında API çağrısı YOK. 450 anahtar.

Mimari:
- `lib/i18n/dictionaries/tr.json` kaynak; `en.json` üretilen; `en.source.json` her EN metnin
  hangi TR metinden geldiğini tutar (TR değişmedikçe yeniden çevrilmez → elle düzeltmeler korunur).
- `lib/i18n/index.tsx` — `LanguageProvider` (kök layout), `useT()` / `useLang()` / `useI18n()` /
  `fmt()` / `currentDict()`. Depo `useSyncExternalStore`, sunucu anlık görüntüsü hep "tr".
  `const en: Dictionary = enDict` ataması sayesinde eksik anahtar derlemede patlar.
- `currentDict()` React dışı saf yardımcılar için: `formatWait`, `timeAgo`, `txLabel`,
  bildirim metinleri, login hata haritası. Bildirimler olay anında okunur.
- `scripts/i18n-translate.mjs` — `{isim}` yer tutucularını `<span translate="no">` ile koruyup
  HTML modunda çevirir; bozulanları uyarır. `--all`, `--dry`.
- Anahtar: `GOOGLE_TRANSLATE_API_KEY` yalnızca `.env.local`'da (Google Cloud "pmj-translate",
  YouTube ile aynı proje). Vercel'e GEREK YOK.
- `LangToggle` konumları: SiteHeader, SiteFooter, kuyruk sayfası başlığı, gözat başlığı,
  Ayarlar > DİL. `BilingualLegal` global dile bağlı.

Kapsam: ana sayfa, /mekanlar, yasal sayfalar ve müşteri paneli (kuyruk, gözat, arama, şarkı
detayı, jeton, profil, ayarlar, geçmiş, favoriler, istekler, giriş, ödeme yöntemleri) çevrildi.
**Mekan admin paneli, super-admin ve `YouTubePlayer` bilinçli olarak Türkçe** — personel kullanır.

**Why:** Sunucuda `cookies()` okunsaydı kök layout dinamikleşir, mekan kabuklarının statik/PPR
üretimi bozulurdu (bkz. [[pmj-perf-rework-2026-07]], [[next16-instant-validation]]).

**How to apply:** Yeni müşteri-yüzü metni doğrudan JSX'e yazma — `tr.json`'a anahtar ekle,
`useT()` ile oku, `npm run i18n:translate` çalıştır, **sonra çıktıyı mutlaka gözden geçir.**
Google "çal-" kökünü sürekli yanlış çeviriyor: "Son Çalınanlar"→"Recently Stolen Items",
"KUYRUK"→"TAIL", "Çalıyor"→"It's ringing", "tarayıcı"→"scanner", "Hesap"→"Bill", "yaz"→"Summer".
Bölünmüş cümleler (prefix + link/bold + suffix) İngilizce söz dizimine göre elle yeniden bölünmeli.
Bilinen taviz: İngilizce seçili kullanıcı ilk boyamada TR görüp hidrasyonda EN'e döner; `metadata`
(SEO) ve hesap silme onay ifadesi ("HESABIMI SİL", sunucuda doğrulanıyor) TR sabit.
